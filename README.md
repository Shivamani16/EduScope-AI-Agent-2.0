# EduScope AI Agent 2.0

## Student Success Intelligence System

EduScope AI Agent 2.0 is an AI-powered student success platform designed to identify academic risks, provide explainable insights, and generate personalized learning and career recommendations.

### Features

* Academic Risk Prediction
* AI-Powered Reasoning
* Personalized Study Recommendations
* Learning Roadmaps
* Career Guidance
* Student Performance Dashboard

### Tech Stack

#### Frontend

* React.js
* Tailwind CSS

#### Backend

* Node.js
* Express.js

#### Database

* MongoDB

#### AI

* Azure AI Foundry
* OpenAI Models

### Project Goal

To help students improve academic performance through intelligent analysis, personalized guidance, and actionable recommendations.
